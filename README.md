# Running from source
1) Clone Repository
git clone https://github.com/bimbim-byte/simple-sekata-checker.git

2) Open folder
cd simple-sekata-checker

3) Install Dependencies
pip install -r requirements.txt

4) Run this command on your command prompt
```py
[windows] python main.py
[linux]   python3 main.py
```
Once the server is running, type `localhost:5000` or `http://127.0.0.1:5000` on any browser. You can press `Ctrl+C` on your command prompt to stop the server.
